# 내 몸 기록 (갱년기 케어 웹앱)

갱년기 증상을 **하루 10초** 만에 기록하고, 모인 기록을 **병원에서 보여 줄 요약**으로 정리해 주는 웹앱입니다.
설치 없이 링크로 열고, "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다. 서버가 없고 **모든 기록은 그 휴대폰 안(IndexedDB)에만** 저장됩니다.

> 이 앱은 의학적 진단을 대신하지 않습니다. 걱정되는 증상은 꼭 의사와 상담하세요.

## 화면

| 탭 | 하는 일 |
|---|---|
| 오늘 | 기분(얼굴 5개), 증상 카드(누를 때마다 없음→조금→보통→심함), 수면, 월경, 메모. 누르는 즉시 저장되고 "되돌리기"가 뜹니다. "◀ 어제"로 지난 날도 기록합니다. 오른쪽 위 ⚙️가 설정입니다. |
| 기록 | 달력(날마다 기분 얼굴, 월경한 날은 빨간 점), 그래프(2주/1달/3달, 증상 3개까지 겹쳐 보기, 한 줄 요약), 병원용 요약 |
| 습관 | 오늘의 체크리스트, 연속으로 챙긴 날, 이번 주 달성률 |
| 정보 | 쉬운 정보 카드 7개 (`src/content/*.md`) |

## 로컬에서 실행하기

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev        # 개발 서버: http://localhost:5173
npm test           # 테스트 (로직 + 화면)
npm run build      # 배포용 파일을 dist/ 에 만든다
npm run preview    # 만든 dist/ 를 http://localhost:4173 에서 미리 보기 (오프라인 동작 확인은 이걸로)
```

같은 와이파이의 휴대폰에서 보려면 `npm run dev -- --host` 후 화면에 나오는 `Network:` 주소로 접속합니다.
(단, 서비스 워커·홈 화면 추가는 `https` 주소에서만 제대로 됩니다. 실제 확인은 배포한 주소로 하세요.)

## 배포하기

정적 파일만 있으면 되므로 어느 정적 호스팅이든 됩니다. 화면 이동이 `#/...` 주소라서 별도 서버 설정이 필요 없습니다.

### 방법 1. GitHub Pages (지금 쓰는 방식)

배포 주소: **https://musuuo.github.io/menopause-care/**

고친 내용을 다시 배포하려면:

```bash
git add . && git commit -m "고친 내용"   # 코드 저장(선택이지만 권장)
git push                                  # 코드를 GitHub에 올림
npm run deploy                            # 테스트 → 빌드 → gh-pages 브랜치에 올림
```

`scripts/deploy.sh` 가 저장소 이름으로 하위 경로(`/menopause-care/`)를 맞춰 빌드하고, `dist/` 내용을 `gh-pages` 브랜치에 덮어씁니다.
저장소 **Settings → Pages** 는 "Deploy from a branch → `gh-pages` / (root)" 로 되어 있어야 합니다.

> GitHub Actions 자동 배포를 쓰지 않은 이유: 이 컴퓨터의 GitHub 로그인 권한에 워크플로 파일을 올리는 권한(`workflow`)이 없어서입니다.
> `gh auth refresh -s workflow` 로 권한을 추가하면 Actions 방식으로 바꿀 수 있습니다.

다른 하위 경로에 직접 올릴 때는 `BASE_PATH=/경로/ npm run build` 로 빌드합니다.

### 방법 2. Netlify 끌어다 놓기 (가장 간단)

1. `npm run build`
2. https://app.netlify.com/drop 에 로그인하고 `dist` 폴더를 끌어다 놓습니다.
3. 나온 `https://...netlify.app` 주소를 씁니다. (고칠 때마다 다시 빌드해서 끌어다 놓으면 됩니다.)

### 업데이트가 휴대폰에 반영되는 방식

새 버전을 배포하면(`npm run deploy`), 앱을 다음에 열 때 뒤에서 새 파일을 받고 그다음 열 때부터 새 버전이 보입니다(서비스 워커 자동 업데이트). 기록은 그대로 남습니다.

## 어머니 휴대폰에서 홈 화면에 추가하기

카카오톡으로 주소를 보내 드리면 카카오톡 안의 브라우저로 열립니다. **그 상태로는 홈 화면 추가가 안 되니** 꼭 아래 브라우저로 다시 여세요.
앱을 처음 열면 3번째 안내 화면에 그림 설명이 나오고, 나중에는 ⚙️ 설정 → "홈 화면에 추가하는 방법"에서 다시 볼 수 있습니다.

### 아이폰

1. 카카오톡에서 링크를 열었다면 오른쪽 아래 `⋯`(또는 공유) → **"Safari로 열기"**(다른 브라우저로 열기).
2. Safari 화면 아래 가운데 **공유 단추(네모에 위쪽 화살표)** 를 누릅니다.
3. 메뉴를 위로 밀어 **"홈 화면에 추가"** → 오른쪽 위 **"추가"**.
4. 홈 화면의 하트 모양 **"내 몸 기록"** 을 누르면 주소창 없이 앱처럼 열립니다.
5. (선택) 알림을 쓰려면 **홈 화면의 앱에서** ⚙️ 설정 → 매일 기록 알림 → 켜기 → 허용. (iOS 16.4 이상, 홈 화면에 추가한 앱에서만 됩니다.)

### 갤럭시 등 안드로이드

1. 카카오톡에서 링크를 열었다면 오른쪽 위 `⋮` → **"다른 브라우저로 열기"** → Chrome 또는 삼성 인터넷.
2. Chrome: 오른쪽 위 `⋮` → **"홈 화면에 추가"** 또는 **"앱 설치"** → **"설치/추가"**.
   삼성 인터넷: 아래 `≡` → **"현재 페이지 추가" → "홈 화면"**.
3. 홈 화면의 **"내 몸 기록"** 아이콘으로 엽니다.

### 꼭 알려 드릴 것

- 기록은 **그 휴대폰의 그 브라우저(앱)** 안에만 있습니다. 브라우저 데이터를 지우거나 앱을 지우면 기록도 사라집니다.
- 휴대폰을 바꾸기 전에는 ⚙️ 설정 → **"백업 파일 만들기"** → 카카오톡 "나와의 채팅"에 파일을 보내 두고, 새 휴대폰에서 그 파일을 저장한 뒤 **"백업 파일로 되살리기"** 를 누르면 됩니다.
- 아이폰에서는 Safari로 연 것과 홈 화면 앱의 저장 공간이 따로입니다. **홈 화면에 추가한 앱에서만 기록하세요.**

## 프로젝트 구조

```
src/
  types.ts, defaults.ts     데이터 모델(기획서 5장), 기본 증상·습관 목록, 화면 문구 상수
  date.ts                   "YYYY-MM-DD" 로컬 날짜 계산
  db.ts                     IndexedDB(idb) 저장소: logs, kv(설정·목록·닫은 안내)
  store.tsx                 설정·목록 상태, 글씨 크기 적용
  useDayLog.ts              하루 기록 불러오기 + 바로 저장 + 되돌리기
  logic/
    warnings.ts             주의 신호 4가지 판정
    stats.ts                추세, 한 줄 요약, 병원용 요약 집계, 그래프 값
    habits.ts               연속 달성일, 이번 주 달성률
    backup.ts               백업 만들기·검사·스키마 마이그레이션
  screens/                  오늘, 기록, 병원용 요약, 습관, 정보, 설정, 온보딩
  components/               하단 탭, 토스트·확인 창, 그래프(SVG), 설치 안내 그림 등
  content/*.md              정보 카드 내용 (파일 이름 순서대로 표시)
scripts/make-icons.mjs      앱 아이콘 PNG 생성 (npm run icons)
```

### 정보 카드 고치기

`src/content/` 의 `.md` 파일을 고치면 됩니다. 첫 줄 `<!-- icon: 🌸 -->`, 다음 줄 `# 제목`, 본문은 빈 줄로 문단을 나누고 `## 소제목`, `- 목록`, `**굵게**` 만 씁니다. 새 파일을 `08-...md` 처럼 추가하면 목록 끝에 붙습니다.
의료 고지 문구는 모든 카드 아래에 자동으로 붙습니다.

### 데이터 형식이 바뀔 때

`src/defaults.ts` 의 `SCHEMA_VERSION` 을 올리고, `src/logic/backup.ts` 의 `migrations` 에 이전 버전 → 새 버전 변환 함수를 추가합니다. 백업 파일 형식은 `{ app: "menopause-care", schemaVersion, exportedAt, logs, symptomDefs, habitDefs, settings }` 입니다.

## 주의 신호 판정 기준

`src/logic/warnings.ts`, 테스트는 `warnings.test.ts`.

| 신호 | 판정 |
|---|---|
| 폐경 후 출혈 | 출혈 기록이 있는 날, 바로 전 출혈일(없으면 첫 기록일)로부터 **365일 이상** 지났을 때 |
| 매우 많은 출혈 | 출혈량 "매우 많음"이 기록된 날 |
| 기분 저하 | 어느 14일 동안 기분 "아주 나쁨"(1점)이 **10일 이상** (이어지는 구간은 하나로 합침) |
| 두근거림 | "심함"이 **달력상 3일 연속** (기록이 하루 빠지면 연속이 아님) |

오늘 화면에는 끝난 지 14일 안의 신호만, "알겠어요"로 닫지 않은 것만 보여 줍니다. 병원용 요약에는 기간 안의 신호가 모두 나옵니다.

## 결정 사항

기획서에 없던 부분은 "단순하고 어르신이 쓰기 쉬운 쪽"으로 정했습니다.

**기술**
- **스타일은 CSS Modules·Tailwind 대신 전역 CSS 파일 하나**(`src/index.css`)와 `:root` 디자인 토큰. 화면 수가 적어 이 쪽이 가장 단순하고, 의존성이 없습니다.
- **그래프는 라이브러리 없이 SVG로 직접** 그렸습니다. 꺾은선만 쓰고, 색 외에 **선 모양(실선·긴 점선·짧은 점선)과 점 모양(●■▲)** 으로도 구분합니다.
- **라우팅은 해시 방식**(`#/records/summary`) 직접 구현. 어떤 정적 호스팅에서도 새로고침 문제가 없습니다.
- 크기는 모두 `rem`. 루트 글자 크기 20px, "크게"를 고르면 24px(+20%)로 전체가 함께 커집니다.
- 날짜 키는 기기 로컬 시간 기준. 미래 날짜는 기록할 수 없습니다.
- 아이콘·그림은 이모지와 직접 그린 SVG만 씁니다(외부 이미지·글꼴·스크립트 없음, 추적 없음).

**화면과 문구**
- 저장 알림은 1.5초. 다만 **되돌리기 버튼이 있는 알림은 4초** 보여 줍니다(1.5초는 누르기에 너무 짧아서). 되돌리기는 바로 전 한 번의 변경만 되돌립니다.
- 메모는 글자를 칠 때마다 저장하지 않고, 입력을 멈추고 1.2초 뒤 또는 입력 칸을 벗어날 때 저장합니다.
- 기획서의 "인쇄 / PDF로 저장" 버튼 이름은 영어 금지 원칙에 맞춰 **"인쇄하기 / 파일로 저장"** 으로 바꿨습니다. (인쇄 창에서 "PDF로 저장"을 고르면 됩니다.)
- 설치 안내에서도 "사파리", "크롬"처럼 한글로 씁니다. 화면에 영어 단어가 없는지는 테스트(`screens.test.tsx`)가 검사합니다.
- 월경 선택지는 360px 화면에서 글자가 잘리지 않도록 3칸 + 2칸으로 놓았습니다.
- **달력 칸은 폭이 약 46px** 입니다. 360px 화면에 7칸을 넣으면 56px 폭이 불가능하므로, 대신 높이를 56px 이상으로 하고 날짜를 누르면 그날 기록 화면(크게)으로 넘어가게 했습니다. 그 밖의 모든 버튼은 56×56px 이상입니다.
- 지난 날짜로 가면 "다음 날 ▶"과 "오늘 기록으로 돌아가기"가 함께 나옵니다.
- 주의 신호 안내는 오늘 화면 맨 위에 카드로, "자세히 보기"(정보 7번 카드)와 "알겠어요"(닫기) 두 버튼만 둡니다.

**계산**
- 증상 통계에서 "기록한 날" = 기분·수면·월경·증상·메모 중 하나라도 기록한 날. **습관만 체크한 날은 증상 통계에서 뺍니다**(증상 "없음"으로 잘못 세지 않도록). 기록한 날에 누르지 않은 증상은 "없음"으로 봅니다.
- **추세**: 병원용 요약은 기간의 앞 절반과 뒤 절반, 그래프 한 줄 요약은 이번 기간과 바로 앞 같은 길이 기간의 평균 단계(0~3)를 비교합니다. 차이가 0.3단계 이상이면 늘어남/줄어듦, 어느 쪽이든 기록이 3일 미만이면 "기록 부족", 한 번도 없던 증상은 "없었음".
- **월경 시작일**: 출혈이 있고 앞 7일 안에 출혈 기록이 없는 날. 월경 중 하루 기록을 빠뜨려도 새 월경으로 세지 않습니다. "최근 월경 간격"은 마지막 두 시작일 사이 일수입니다.
- **연속 달성일**: 습관을 **하나라도** 챙긴 날이 이어진 수(모두 해야 하는 기준은 부담스러워서). 오늘 아직 안 했으면 어제까지의 연속을 보여 줍니다. 이번 주는 월요일부터입니다.
- 그래프는 처음 열 때 이번 기간에 가장 많이 나타난 증상을 최대 3개 골라 둡니다.
- 병원용 요약은 A4 한 장에 맞추려고 **인쇄할 때 메모를 최근 10개만** 싣고 나머지 개수를 적습니다(화면에서는 모두 보입니다). 숨긴 증상도 그 기간에 기록이 있으면 요약에 나옵니다.

**알림**
- 서버가 없어 진짜 푸시 알림은 보낼 수 없습니다. 앱이 열려 있거나 잠시 뒤로 가 있는 동안 정한 시간이 되면, **오늘 기록이 없을 때만 하루 한 번** 알림을 띄웁니다. 휴대폰이 앱을 완전히 닫으면 오지 않을 수 있다는 점과, 휴대폰 알람을 함께 맞추면 좋다는 점을 설정 화면에 적어 두었습니다. (푸시 고도화는 기획서대로 2단계)
